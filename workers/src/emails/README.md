# 通知メールのテンプレート

文言はこのディレクトリの `.txt` を直接編集する。コードもテストも触らなくてよい。
Wrangler が `.txt` を文字列モジュールとして取り込むので、ビルド設定も不要。

## 書式

```
Subject: 写真が{{count}}枚届いています

FurDrop に新しい写真が届きました。

> {{count}}枚 / {{senders}}から

  ギャラリーで見る
  {{gallery_url}}
```

- **1 行目が `Subject:`**、空行を挟んで以降が本文 (`footer` だけは Subject を持たない)
- 空行で区切ると段落になる
- `> ` で始まる行は**リード行**（一回り大きい太字）。数字を最初に読ませたいときに使う
- **字下げしたラベル行 + 字下げした URL 行**は **CTA ボタン**になる。テキストパートではラベルと URL のまま残る
- **本文中の裸の URL はリンクにならない** (テキストのまま出る)。リンクにしたければ CTA ボタンか
  フッターを使う。本文を自動リンク化すると、ダイジェストのリード行に入る送信者名 (匿名の
  送信者が自由に入力できる) が、furdrop.app から届くメール内のクリック可能なリンクになってしまう

HTML は本文から機械的に組み立てる (`lib/email-layout.ts`)。テンプレートに HTML を書く必要はないし、書いてもエスケープされる。

## プレースホルダ

`{{name}}` は呼び出し側が渡す値に置換される。**未定義の名前を書くと描画時に例外になる**ので、
下の表にないものは使えない (増やしたいときは呼び出し側も直す)。

| テンプレート | 使える名前 |
|---|---|
| `digest` | `count` `senders` `gallery_url` |
| `expiry` | `count` `days` `gallery_url` |
| `quota` | `percent` `used` `quota` `gallery_url` |
| `verify` | `email` `verify_url` |
| `footer` | `unsubscribe_url` `settings_url` |

`footer` は `verify` 以外の全メールの末尾に自動で付く（確認メールには解除するものが無いので付かない）。
フッターの行は **`ラベル: URL`** の形で書く。HTML ではラベルだけがリンクになる（解除 URL は
トークンを含んで長く、そのまま出すと折り返して読めなくなる）。テキストパートでは URL が残る。

### 複数形

英語だけ `{{plural 変数|単数形|複数形}}` が使える。日本語では使わない。

```
Subject: {{count}} new {{plural count|photo|photos}}
```

## 守ること

### 広告・宣伝を書かない

**有料プランの案内、アップグレードの勧誘、キャンペーンの類を書いてはいけない。**

通知メールが特定電子メール法の「特定電子メール」に当たらないという整理は、本文に広告・宣伝が
無いことに依存している。付随的な広告であっても、同法 3 条 3 項ただし書が免除するのは 4 条
**2 号**（受信拒否用アドレスの表示）だけで、**4 条 1 号の「氏名又は名称」の表示義務は残る**。
個人事業のため、これは運営者の本名を全メールに載せることを意味する。

容量警告に有料プランを書きたくなるが、**メールは「容量が逼迫している / 確認する」で止めて、
案内はリンク先のアプリ画面に置く**こと。特定電子メール法は電子メールの法律なので、アプリ内の
表示には及ばない。詳細は `docs/research/email-notification-legal.md`。

### 外部ドメインの画像を貼らない・開封トラッキングを入れない

電気通信事業法 27 条の 12（外部送信規律）がグレーになる。ロゴは画像ではなくテキストで描画
している（画像をブロックするメールクライアントで差出人が分からなくなるのを避ける意味もある）。

## 確認のしかた

`pnpm --filter workers dev` を起動して、ブラウザで開く（本番ではマウントされない）:

```
http://localhost:9000/dev/emails/digest/ja        HTML
http://localhost:9000/dev/emails/digest/ja?text=1 テキストパート
http://localhost:9000/dev/emails                  一覧
```

`workers/test/email-templates.test.ts` が、全テンプレートを描画して
**`{{` の消し忘れ**と **ja / en のプレースホルダ不一致**を検出する。文言を変えたら
`pnpm test:workers` を回す。
