# プライバシーポリシー

最終更新日: 2026年8月15日 / 制定日: 2026年5月3日

FurDrop（個人事業主による運営。以下「当サービス運営者」といいます）は、写真受信ウェブサービス「FurDrop」（以下「当サービス」といいます）における個人情報の取扱いについて、本プライバシーポリシー（以下「本ポリシー」といいます）のとおり定めます。本ポリシーは、当サービスの利用規約（以下「利用規約」といいます）と一体をなすものです。

## 1. はじめに（適用範囲）

1. 本ポリシーは、当サービス運営者が、当サービスの提供に関連して取得・利用する個人情報、個人データおよびこれに準ずる利用者情報（以下総称して「個人情報等」といいます）の取扱いを定めるものです。
2. 本ポリシーは、当サービスを利用するすべての方（以下「お客様」といい、利用規約に定める受信者および送信者を含みます）に適用されます。
3. 当サービスは、日本国内のお客様による利用を想定しています。日本国外からのアクセスおよび利用について、当サービスは積極的に提供を行うものではなく、欧州一般データ保護規則（GDPR）、英国一般データ保護規則（UK GDPR）、カリフォルニア州消費者プライバシー法（CCPA）その他の日本国外の法令に基づく権利・義務には対応していません。
4. 本ポリシーは、民法第548条の2に定める定型約款の一部として位置付けられます。

## 2. 取得する個人情報の項目

当サービスは、以下の項目を取得します。

### 2.1 受信者から取得する情報

1. Firebase Authentication（X または Google アカウントによるログイン）を介して取得する情報
   1. Firebase ユーザーID（UID）
   2. メールアドレス（IDPから提供される範囲）
   3. 表示名（IDPから提供される範囲）
   4. アバター画像のURL（IDPから提供される範囲）
2. 受信者がアカウント設定画面で入力または選択した情報
   1. ハンドル（公開URLの一部として公開）
   2. 表示名
   3. 受信オプション設定（送信者名の入力必須および透かしの許可有無）
   4. プッシュ通知の有効/無効設定
3. プッシュ通知のため、受信者の端末から取得する Firebase Cloud Messaging（FCM）デバイストークン
4. 当サービス内における利用状況に関する情報（ストレージ使用量、保有写真件数、登録日時、最終更新日時等）

### 2.2 送信者から取得する情報

1. アップロードに関するアクセスログ
   1. IPアドレス
   2. ユーザーエージェント
   3. アクセス日時およびタイムスタンプ
2. 送信者が任意で入力する情報
   1. 送信者名（X のID等を含むことがあります）
   2. 透かし（ウォーターマーク）に用いるテキストおよび設定値
3. アップロードされた写真およびそのメタデータ
   1. 画像データ（受信者のストレージに保管されます）
   2. ファイル名、ファイルサイズ、解像度
   3. 写真ファイルに含まれる EXIF 等のメタデータ。ただし、EXIF GPS情報（位置情報）は、送信時にクライアント側で既定で除去されます。

### 2.3 共通して取得する情報

1. アクセス時の通信ログ（HTTPリクエスト・レスポンスに関する技術情報、エラーログ等）
2. Cookie および類似技術によりブラウザに保存される情報（第9項参照）

## 3. 利用目的

当サービス運営者は、取得した個人情報等を、以下の目的のためにのみ利用します（個人情報の保護に関する法律（以下「個情法」といいます）第17条に基づく利用目的の特定）。

1. 当サービスの提供および運営（写真の受領、保管、配信、サムネイル生成、ダウンロード提供を含みます）
2. 受信者の本人確認および認証
3. プッシュ通知（新着写真の通知）の配信
4. ストレージ利用状況の表示および管理
5. ハンドルおよび公開URLによる受信者プロフィールの公開
6. 不正利用、不正アクセス、規約違反その他の不適切な利用の検知・防止および対応
7. 情プラ法第5条その他の法令に基づく発信者情報開示請求等への対応、紛争対応および法的請求への対応
8. お問い合わせ・通報・削除依頼への対応
9. 当サービスの改善、新機能の検討および品質の維持
10. 利用規約・本ポリシーの変更通知その他お客様への重要なお知らせの送付
11. その他、上記利用目的に付随する目的

## 4. 第三者提供

1. 当サービス運営者は、以下のいずれかの場合を除き、お客様の個人データを第三者に提供しません（個情法第27条）。
   1. お客様の同意がある場合
   2. 法令に基づく場合
   3. 人の生命、身体または財産の保護のために必要がある場合であって、お客様の同意を得ることが困難であるとき
   4. 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合であって、お客様の同意を得ることが困難であるとき
   5. 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合
2. 受信者は、自らの公開URLおよびハンドルが当サービス上で公開されること、ならびに送信者から自らに送信された写真および付随情報（送信者名等）が、第6条の業務委託先のサーバを経由して受信者に提供されることに、あらかじめ同意するものとします。

1. 当サービス運営者は、利用目的の達成に必要な範囲で、個人データの取扱いを委託することがあります（個情法第27条第5項第1号）。
2. 当サービス運営者は、委託先について、個人データを安全に管理するために必要かつ適切な監督を行います。

主要な委託先は次のとおりです。

## 6. 外国にある第三者への提供および外的環境の把握

1. 当サービスは、第5項の委託に伴い、お客様の個人データを、米国に所在する委託先のサーバ（Cloudflare, Inc. および Google LLC が運営するもの）において取り扱います（個情法第28条関係）。
2. 当サービス運営者は、米国における個人情報の保護に関する制度を把握したうえで、お客様の個人データの安全管理に必要かつ適切な措置を講じています（外的環境の把握。個人情報保護委員会ガイドライン通則編「10-7 外的環境の把握」関係）。
3. 米国の個人情報の保護に関する制度の概要については、個人情報保護委員会が公表する以下の資料等をご参照ください。
   - 個人情報保護委員会「外国における個人情報の保護に関する制度等の調査」 https://www.ppc.go.jp/personalinfo/legal/kaiseihogohou/
4. 当サービス運営者は、委託先との間で締結する契約および委託先が公表する標準約款・データ処理に関する追補（DPA）等に基づき、適切な保護措置を講じます。

## 7. 安全管理措置

当サービス運営者は、個人データの漏えい、滅失または毀損を防止するため、次の各号に掲げる安全管理措置を講じています。具体的な措置の内容は、第8項に基づくお問い合わせを通じて、合理的な範囲でご案内します。

1. 組織的安全管理措置：個人データの取扱責任者を定め、取扱状況を把握できる体制を整備しています。漏えい等の事案発生時の対応手順を整備しています。
2. 人的安全管理措置：個人データの取扱いに関する留意事項を定め、これを遵守して業務を行っています。
3. 物理的安全管理措置：個人データを取り扱う端末について、盗難・紛失防止措置および記録媒体の適切な管理を行っています。
4. 技術的安全管理措置：通信経路の暗号化（TLS）、アクセス制御、認証、ログ記録、最小権限の原則等を適用しています。R2 ストレージ上のオブジェクトはプライベート設定とし、署名付きURLを介してのみアクセスできるようにしています。
5. 外的環境の把握：第6項に定めるとおり、米国における個人情報の保護に関する制度を把握したうえで、安全管理措置を講じています。

## 8. 保有個人データに関する事項

個情法第32条第1項に基づき、保有個人データに関する次の事項を公表します。

1. 個人情報取扱事業者の名称
   FurDrop（個人事業主による運営）
2. 代表者の氏名および住所
   個人事業主による運営のため、代表者の氏名および住所は本ポリシー上では非公表とします。本人確認のうえ、当サービスの[お問い合わせフォーム]を通じてご請求いただいた場合、当サービス運営者は遅滞なく回答します（個情法第32条第1項括弧書きに基づく取扱い）。
3. すべての保有個人データの利用目的
   本ポリシー第3項に定める利用目的のとおりです。
4. 保有個人データの開示等請求の手続
   1. お客様（本人または法定代理人もしくは委任された代理人）は、自己の保有個人データについて、利用目的の通知、開示（第三者提供記録を含みます）、訂正、追加、削除、利用停止、消去、第三者提供の停止を請求することができます。
   2. 請求は、当サービスのフッターに掲載するお問い合わせフォームを通じて受け付けます。
   3. 当サービス運営者は、請求受付後、合理的な方法（IDP認証によるログインの確認、ご本人しか知り得ない情報の照会等）により本人確認を行います。代理人による請求の場合、代理権を証する書類の提示をお願いすることがあります。
   4. 回答は、原則として当サービス運営者が指定する方法（電子的記録による開示等）により行います。
   5. 開示等請求に係る手数料は、原則として無料とします。ただし、利用目的の通知および開示について、合理的な範囲を超える対応を要する場合、実費を申し受けることがあります。
   6. 法令に基づき開示等請求に応じる義務がない場合（請求者が本人であることを確認できない場合、法令に違反することとなる場合等）、お申出に応じられないことがあります。
5. 苦情の申出先
   保有個人データの取扱いに関する苦情は、当サービスのフッターに掲載するお問い合わせフォームを通じて受け付けます。
6. 認定個人情報保護団体
   当サービス運営者は、認定個人情報保護団体に加入していません。

## 9. Cookie・ローカルストレージ等の利用

1. 当サービスは、お客様の利便性向上、セッション維持、認証状態の維持、利用状況の把握、不正利用の防止等のため、Cookie、ローカルストレージその他のブラウザ上の保存技術（以下「Cookie等」といいます）を利用することがあります。
2. お客様は、ブラウザの設定により Cookie 等の利用を制限することができます。ただし、Cookie 等を制限した場合、当サービスの一部機能（認証状態の維持等）を正常に利用できないことがあります。
3. 当サービスは、現時点では第三者の広告配信事業者によるトラッキング Cookie を利用していません。将来導入する場合、本ポリシーを改定し、第10項の外部送信先一覧に追記したうえで公表します。

## 10. 外部送信に関する公表（電気通信事業法第27条の12対応）

当サービスは、電気通信事業法上、不特定の利用者間の通信を媒介する電気通信役務として運営されます。送信者は、受信者の公開URL（ハンドル）を知る不特定の者であり、当サービス運営者は、送信者と受信者の間の写真の送受を媒介する立場にあります。

当サービスは、お客様の端末（ブラウザ等）から、当サービス以外の事業者の電気通信設備に対し、お客様に関する情報の送信を行わせることがあります。送信される情報、送信先、利用目的は次のとおりです。

| 送信先（事業者・所在国） | 送信される情報の内容 | 送信先における利用目的 | お客様の対応 |
|---|---|---|---|
| Google LLC（米国）／Firebase Authentication | IDトークン、Firebase UID、メールアドレス、認証セッション情報 | 受信者の認証（本人確認、ログイン状態の維持） | ログインしない場合は送信されません |
| Google LLC（米国）／Firebase Cloud Messaging（FCM） | FCM デバイストークン、デバイス情報、プッシュ通知の配信に必要な情報 | 新着写真等のプッシュ通知の配信 | 受信者は設定画面でプッシュ通知をオフにできます |
| Cloudflare, Inc.（米国）／R2、D1、Workers、Pages | アップロード写真、サムネイル、リクエスト内容、IPアドレス、ユーザーエージェント、認証トークン、Cookie | ホスティング、データ保存、通信仲介、不正利用検知 | 当サービスの利用に必要であり、停止できません |

将来、解析ツール（アナリティクス等）その他の外部送信を伴うサービスを導入する場合、当サービス運営者は、本ポリシーを改定し、本表に追記したうえで、効力発生前に公表します。

## 11. 保有期間

当サービス運営者は、取得した個人情報等を、利用目的の達成に必要な期間に限り保有します。具体的な保有期間は次のとおりです。

| 情報種別 | 保有期間 |
|---|---|
| アップロード写真およびサムネイル | アップロード日から原則として365日（経過後は自動削除）。受信者による任意削除またはアカウント削除の場合は当該削除時 |
| 受信者アカウント情報（Firebase UID、メールアドレス、表示名、ハンドル、設定情報、FCMトークン等） | アカウントが有効である間。退会・アカウント削除時に削除 |
| 送信者の通信記録（IPアドレス、ユーザーエージェント、タイムスタンプ等） | 当該送信から最低3か月（利用規約第13条に基づく）。紛争・法的請求が現実化した個別事案については、解決まで延長 |
| アクセスログその他の運用上のログ | 原則として90日 |
| お問い合わせ対応に関する記録 | 対応完了後、合理的な期間（紛争対応等のため最長5年程度） |

法令に基づき長期の保存が義務付けられる情報については、当該法令に従って保存します。

## 12. 未成年者の利用

1. 当サービスは、当サービス独自の年齢制限を設けず、Firebase Authentication が利用するIDP（X または Google）の年齢制限に依拠します。
2. 未成年者が当サービスを利用する場合、法定代理人の同意を得たうえで利用してください。法定代理人は、未成年者の個人情報の取扱いについて、本ポリシーをご確認のうえ同意するものとします。
3. 法定代理人は、未成年者に代わって、第8項に定める開示等請求を行うことができます。

2. 本ポリシーが個情法上の利用目的の変更等、お客様の権利義務に重要な影響を及ぼす変更を含む場合、当サービス運営者は、変更後の本ポリシーの内容および効力発生時期を、当サービス上の掲示その他の適切な方法により事前に告知します。
3. 効力発生時期の経過後にお客様が当サービスを利用した場合、変更後の本ポリシーに同意したものとみなされます。

## 14. お問い合わせ窓口

本ポリシー、当サービスにおける個人情報等の取扱い、開示等請求、苦情その他のお問い合わせは、以下の窓口にて受け付けます。

- 受付方法: 当サービスのフッターに掲載する[お問い合わせフォーム]
