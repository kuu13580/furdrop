# 利用規約

最終更新日: 2026年5月3日 / 制定日: 2026年5月3日

本利用規約（以下「本規約」といいます）は、FurDrop（個人事業主による運営。以下「当サービス運営者」といいます）が提供する写真受信ウェブサービス「FurDrop」（以下「当サービス」といいます）の利用条件を定めるものです。当サービスを利用するすべての方（以下「お客様」といいます）に適用されます。

本規約は、民法第548条の2に定める定型約款に該当します。お客様は、当サービスを利用することにより、本規約のすべての条項に同意したものとみなされます。

## 第1条（適用範囲・定義）

1. 本規約は、お客様が当サービスを利用するすべての場面に適用されます。
2. 本規約において、次の各号に掲げる用語の意義は、当該各号に定めるところによります。
   1. 「受信者」とは、当サービスにアカウントを登録し、自らに割り当てられた公開URLを通じて写真を受け取る利用者をいいます。
   2. 「送信者」とは、受信者の公開URLにアクセスして、当該受信者に対し匿名で写真を送信する利用者をいいます。
   3. 「アップロード写真」とは、送信者が当サービスを通じてアップロードした画像ファイル（メタデータを含みます）をいいます。
   4. 「ハンドル」とは、受信者が公開URLの一部として用いる識別子（半角英小文字・数字・アンダースコアからなる文字列）をいいます。
   5. 「公開URL」とは、`https://[当サービスのドメイン]/send/[ハンドル]` の形式で表される、受信者ごとの写真受信用URLをいいます。

## 第2条（規約への同意）

1. お客様は、以下の方法により本規約に同意するものとします。
   1. 受信者は、アカウント登録時に画面上で本規約および本規約と一体をなすプライバシーポリシーへの同意を明示的な操作（同意チェックボックス等）により表明することで、当サービス運営者との間で本規約を内容とする利用契約が成立します。
   2. 送信者は、写真の送信を実行する直前の画面で、本規約およびプライバシーポリシーへの同意を明示的な操作（同意チェックボックス等）により表明することで、当該送信に関し本規約を内容とする利用契約が成立します。送信者は、認証を経ない匿名利用者であっても、当該同意操作により本規約に拘束されます。
2. 本規約に同意できない場合、お客様は当サービスを利用することができません。

## 第3条（アカウント登録／受信者）

1. 当サービスの受信者として利用を希望する方は、Firebase Authentication を介した X（旧 Twitter）または Google アカウントによる認証（以下「IDP認証」といいます）を経たうえで、ハンドルおよび表示名を登録するものとします。
2. ハンドルは、半角英小文字・数字・アンダースコアからなる3文字以上32文字以下の文字列とし、当サービス内で一意である必要があります。
3. 受信者は、登録情報を正確かつ最新の状態に保つものとします。
4. 受信者は、IDP認証に用いるアカウントの管理について、自らの責任で行うものとします。当該アカウントの不正利用により受信者または第三者に損害が生じた場合、当サービス運営者は、当サービス運営者に故意または重過失がない限り、その責任を負いません。

   2. 過去に本規約違反等により利用停止処分を受けたことがある場合
   3. その他、当サービス運営者が受信者として不適当と合理的に判断した場合

1. 当サービスは、当サービス独自の年齢制限を設けません。ただし、受信者の登録に用いるIDP認証（X または Google）には、各IDPが定める年齢制限が適用されます。お客様は、当該IDPの年齢制限を遵守するものとします。
2. 未成年者が当サービスを利用する場合、法定代理人の同意を得たうえで利用するものとします。法定代理人の同意を得ずに利用契約を締結し、後にこれを取り消す場合があり得ることを、お客様は理解するものとします。

## 第5条（サービス内容）

1. 当サービスは、受信者が公開URLを発行し、送信者が当該URLを通じて受信者に対し写真を匿名でアップロードするためのプラットフォームを提供します。
2. 当サービスは、以下の機能等を含みます。
   1. 受信者ごとの公開URL発行
   2. 送信者からのアップロード写真の受領、保管および受信者への配信
   3. 受信者によるアップロード写真の閲覧、ダウンロードおよび削除
   4. ストレージ利用状況の表示
   5. 新着写真のプッシュ通知
3. 当サービスは、アップロード写真について、原則として受信から30日が経過した時点で自動的に削除します。詳細は第12条に定めます。
4. 当サービス運営者は、当サービスの内容を、合理的な範囲で随時変更することができます。

3. 当サービスは、プライバシー保護の観点から、送信時にクライアント側でアップロード写真のEXIF GPS情報（位置情報）を既定で除去します。送信者は、この処理に同意するものとします。
